# ⚡ دليل المبتدئين لتشغيل مشغل OpenClaude وكالة الذكاء الاصطناعي

مرحباً بك! هذا الدليل مصمم ليأخذك خطوة بخطوة لتشغيل مشروعك على أي جهاز كمبيوتر، حتى لو لم تقم بكتابة كود من قبل.

---

## 🛠️ الخطوة 1: البرامج المطلوبة (تثبيت لمرة واحدة)

قبل البدء، نحتاج لتثبيت 3 برامج أساسية على جهازك الجديد:

1.  **Node.js**: المحرك الذي يشغل المشروع.
    *   [حمل نسخة LTS من هنا](https://nodejs.org/en/download) (اختر Windows Installer).
2.  **Ollama**: لتشغيل الذكاء الاصطناعي محلياً على جهازك مجاناً.
    *   [حمل من هنا](https://ollama.com/download).
3.  **Bun**: أداة سريعة جداً لتجهيز المشروع.
    *   افتح "PowerShell" واكتب هذا الأمر:
        `powershell -c "irm bun.sh/install.ps1 | iex"`

---

## 📂 الخطوة 2: نقل الملفات وتجهيزها

1.  قم بنسخ مجلد المشروع `openclaude-main` إلى الجهاز الجديد.
2.  افتح المجلد، ثم انقر بزر الفأرة الأيمن في مكان فارغ واختر **Open in Terminal** (فتح في التيرمينال).
3.  اكتب الأوامر التالية بالترتيب وانتظر انتهاء كل واحد:

```bash
# تثبيت المكتبات اللازمة
bun install

# بناء المشروع ليصبح جاهزاً للعمل
bun run build
```

---

## 🚀 الخطوة 3: تشغيل لوحة التحكم (Dashboard)

هذه هي الخطوة الأهم والأمتع! للبدء، ابحث عن ملف داخل المجلد باسم:
`start-dashboard.bat`
**انقر عليه مرتين.**

ستفتح لك شاشة سوداء تبدأ بتشغيل الخادم، وبعد ثوانٍ سيفتح متصفحك تلقائياً على واجهة "ChatGPT" الخاصة بك.

---

## 🧠 الخطوة 4: تحميل "عقل" الذكاء الاصطناعي

لكي يبدأ البرنامج بالرد عليك، يجب أن يكون لديه "موديل" مثبت. افتح التيرمينال مرة أخرى واكتب:

```bash
# الموديل الأفضل للبرمجة (حجمه حوالي 4.7GB)
ollama pull qwen2.5-coder:7b

# موديل خفيف جداً وسريع جداً (حجمه حوالي 2GB)
ollama pull llama3.2:3b
```

---

## 💡 نصائح وحلول سريعة:

*   **فشل الاتصال؟**: تأكد أن برنامج Ollama يعمل في خلفية الجهاز (ستجد أيقونة صغيرة بجانب الساعة).
*   **اللغة العربية**: الواجهة تدعم العربية بالكامل، يمكنك التحدث مع الوكلاء بالعربية وسيفهمونك.
*   **مفاتيح API**: إذا أردت استخدام نماذج سحابية قوية مثل Claude 3.5، يمكنك إضافة مفتاحك في صفحة الإعدادات (Settings) داخل الواجهة.

---
