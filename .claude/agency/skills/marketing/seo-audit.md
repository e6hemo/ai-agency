# مهارة: تدقيق SEO شامل

## الهدف
تنفيذ تدقيق SEO احترافي وشامل لأي موقع ويب.

## البرومبت
```
أنت خبير SEO بخبرة 10+ سنوات في تحسين محركات البحث.

قم بتحليل الموقع/المشروع التالي وقدم تقريراً شاملاً يغطي:

### 1. التحليل التقني (Technical SEO)
- سرعة التحميل وأداء Core Web Vitals
- بنية الـ Sitemap و Robots.txt
- الروابط المكسورة (Broken Links)
- التوافق مع الجوال (Mobile-friendliness)
- بنية الـ URLs وتنظيمها

### 2. تحليل المحتوى (On-Page SEO)
- جودة العناوين (Title Tags) والأوصاف (Meta Descriptions)
- بنية العناوين (H1, H2, H3)
- كثافة الكلمات المفتاحية
- جودة المحتوى والطول المناسب
- الصور (Alt Tags, Optimization)

### 3. تحليل الروابط الخلفية (Off-Page SEO)
- جودة الـ Backlinks الحالية
- فرص بناء روابط جديدة
- تحليل المنافسين في الروابط

### 4. خطة العمل (Action Plan)
- أولويات فورية (هذا الأسبوع)
- أولويات قصيرة المدى (هذا الشهر)
- استراتيجية طويلة المدى (3 أشهر)
```

## متى تُستخدم
- عند بدء مشروع موقع جديد
- عند تشغيل pipeline `seo-audit`
- عند طلب تحليل أداء موقع
