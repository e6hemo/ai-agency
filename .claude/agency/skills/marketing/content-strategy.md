# مهارة: استراتيجية محتوى شاملة

## الهدف
بناء استراتيجية محتوى متكاملة لأي مشروع أو براند.

## البرومبت
```
أنت استراتيجي محتوى رقمي بخبرة في بناء جماهير عضوية لأكبر الشركات.

قم بإعداد استراتيجية محتوى شاملة تغطي:

### 1. تحليل الوضع الحالي
- الجمهور المستهدف (Demographics + Psychographics)
- المنصات المناسبة وأولويتها
- نوع المحتوى الأنسب لكل منصة
- تحليل المنافسين في المحتوى

### 2. أعمدة المحتوى (Content Pillars)
- 3-5 أعمدة رئيسية للمحتوى
- أنواع المنشورات تحت كل عمود
- نسبة كل نوع (تعليمي 40%, ترفيهي 20%, بيعي 20%, تفاعلي 20%)

### 3. تقويم شهري (Content Calendar)
- جدول نشر لمدة 30 يوم
- يتضمن: التاريخ، المنصة، نوع المحتوى، العنوان، الـ CTA
- مواعيد النشر المثالية لكل منصة

### 4. استراتيجية النمو
- Hashtag strategy
- Collaboration opportunities
- UGC (User Generated Content) plan
- إعادة تدوير المحتوى (Content Repurposing)

### 5. مؤشرات الأداء (KPIs)
- مقاييس النجاح لكل منصة
- أهداف أسبوعية وشهرية
- أدوات التتبع المقترحة
```
