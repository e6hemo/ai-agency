## 💡 أنماط تصميم مستوحاة

### نمط "ستيلا" (Chief of Staff Pattern)
- **المصدر:** دراسة حالة VC بنى مساعد AI شخصي
- **المبدأ الأساسي:** "AI يتولى الحكم والتفكير. الأكواد تتولى الميكانيكية."
- **التطبيق في وكالتنا:**
  - الوكلاء (Claude/LLM) → التفكير، الصياغة، التحليل، اتخاذ القرارات
  - النظام (TypeScript) → قراءة الملفات، API calls، الجدولة، المقارنة

### نمط "حلقة البحث الكاملة" (Full Research Loop)
- **المصدر:** نظام NotebookLM + Claude Code
- **الحلقة:** هدف → بحث → مقابلة → بروتوكول → تجارب → متابعة يومية → تتبع نتائج
- **التطبيق:** `/api/crawl` → `MemPalace` → Pipeline → `Experiments Tracker`

## 📋 قوالب مهارات سريعة (Quick Skills)

### تحليل SEO سريع
```
Role: أنت خبير SEO بخبرة 10 سنوات.
Task: حلل الموقع التالي [URL] وقدم:
1. أهم 5 مشاكل تقنية
2. أهم 5 فرص محتوى
3. استراتيجية Backlinks لـ 30 يوم
```

### تحليل منافسين
```
Role: أنت محلل استراتيجي في وكالة تسويق.
Task: حلل المنافس [اسم المنافس] وقدم:
1. نقاط القوة والضعف
2. استراتيجيتهم التسويقية
3. الفجوات التي يمكننا استغلالها
```

### كتابة إعلان احترافي
```
Role: أنت مؤلف إعلانات (Copywriter) بأسلوب David Ogilvy.
Task: اكتب إعلاناً لـ [المنتج/الخدمة] يستهدف [الجمهور] بأسلوب:
1. عنوان يجذب الانتباه (Headline)
2. فقرة أولى تخلق مشكلة (Pain Point)
3. الحل (Solution) مع إثبات اجتماعي
4. دعوة للعمل (CTA) واضحة
```

### مراجعة كود أمنية
```
Role: أنت مهندس أمن معلومات (OWASP Certified).
Task: راجع الكود التالي وابحث عن:
1. ثغرات OWASP Top 10
2. API Keys مسربة
3. SQL Injection / XSS
4. مشاكل CORS
```
