# 🕵️ قالب: تحليل منافسين شامل

## المتطلبات
- **مجال العمل:** ___
- **المنافسون للتحليل:** (3-5 منافسين مع روابطهم)
- **السوق المستهدف:** (محلي/إقليمي/عالمي)
- **الجوانب المطلوب تحليلها:** (اختر ما يناسبك)
  - [ ] الموقع الإلكتروني
  - [ ] السوشيال ميديا
  - [ ] SEO والمحتوى
  - [ ] التسعير
  - [ ] الإعلانات
  - [ ] نقاط القوة والضعف

## خطوات التنفيذ

### المرحلة 1: البحث والجمع
1. `@marketing-strategist` — تحليل استراتيجي شامل للمنافسين:
   - نموذج العمل (Business Model)
   - الجمهور المستهدف
   - القيمة المقترحة (Value Proposition)
   - نقاط القوة والضعف (SWOT)

2. `@seo-specialist` — تحليل SEO للمنافسين:
   - الكلمات المفتاحية
   - Domain Authority
   - Backlink profile
   - أداء المحتوى

### المرحلة 2: التحليل العميق
3. `@data-analyst` — تحليل البيانات ومقارنة الأداء:
   - مقارنة الحصة السوقية
   - تحليل الاتجاهات
   - جداول مقارنة تفصيلية

4. `@social-media-manager` — تحليل السوشيال ميديا:
   - استراتيجية المحتوى
   - معدلات التفاعل
   - أفضل المنشورات

### المرحلة 3: التوصيات
5. `@marketing-strategist` — استخلاص الفرص والتهديدات
6. `@marketing-strategist` — إعداد خطة عمل تنافسية

## المخرجات المتوقعة
- ✅ تقرير تحليل منافسين مفصل
- ✅ جداول مقارنة
- ✅ تحليل SWOT لكل منافس

- ✅ فجوات وفرص السوق
