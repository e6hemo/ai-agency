# 🔍 قالب: تحليل SEO شامل

## المتطلبات
- **رابط الموقع:** ___
- **الكلمات المفتاحية الحالية:** (إن وُجدت)
- **المنافسون الرئيسيون:** (2-3 مواقع)
- **السوق المستهدف:** (بلد/منطقة)
- **اللغة:** (عربي/إنجليزي/كلاهما)
- **الأهداف:** (ترتيب أعلى, زيادة زيارات, تحسين تحويلات)

## خطوات التنفيذ

### المرحلة 1: التحليل التقني
1. `@seo-specialist` — فحص SEO تقني شامل:
   - سرعة الموقع (Core Web Vitals)
   - بنية URL والتنقل
   - Schema markup
   - Sitemap و robots.txt
   - Mobile-friendliness
   - أخطاء الزحف (Crawl errors)

### المرحلة 2: تحليل المحتوى
2. `@seo-specialist` — بحث كلمات مفتاحية شامل (Keyword Research)
3. `@seo-specialist` — تحليل المنافسين في SERPs
4. `@data-analyst` — تحليل بيانات الأداء الحالي

### المرحلة 3: خطة التحسين
5. `@seo-specialist` — بناء استراتيجية SEO (On-page + Off-page)
6. `@content-writer` — تحسين المحتوى الحالي + اقتراح محتوى جديد
7. `@seo-specialist` — كتابة Meta descriptions و Title tags محسّنة

### المرحلة 4: التنفيذ التقني
8. `@full-stack-developer` — تطبيق التحسينات التقنية
9. `@code-reviewer` — مراجعة التغييرات

## المخرجات المتوقعة
- ✅ تقرير SEO تقني مفصل
- ✅ قائمة كلمات مفتاحية مستهدفة (50-100 كلمة)
- ✅ تحليل منافسين
- ✅ خطة تحسين مرحلية
- ✅ Meta descriptions و Title tags محسّنة
- ✅ توصيات محتوى جديد
- ✅ تقرير قبل/بعد
